## Purpose

Define a governed path from Tarcie beta-test observations into ZFSS feedback metabolism and, after an explicit human decision, into exactly one of three allowlisted GitHub repositories:

1. Boswell-Digital-Solutions/Forge_Command
2. Boswell-Digital-Solutions/forge-smithy
3. Boswell-Digital-Solutions/zfss

The plan preserves these boundaries:

- Tarcie captures evidence.
- ZFSS owns feedback Signals, feedback Issues, triage, and the canonical handoff proposal.
- Forge_Command presents the decision, performs a separately authorized GitHub write, and records the creation receipt.
- Forge:SMITH consumes accepted engineering work and produces governed remediation evidence.
- No component gains automatic diagnosis, approval, repair, or release authority.
